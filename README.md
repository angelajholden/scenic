Scenic is a static blog-style website that celebrates scenic views in nature.

The project includes a blog, contact page, and page template, plus interaction helpers for menu toggling, contact form metadata, print behavior, and social sharing links.

## Features

- Static multi-page blog layout.
- Faux parallax header section on the homepage.
- Menu toggle and Escape-key close behavior.
- Print button and social sharing helpers.
- Contact form enhancement that stores page URL/path values.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript

## Quick Start

Clone the repo and open `index.html` in your browser, or use the VS Code Live Server extension.

```bash
git clone git@github.com:angelajholden/scenic.git
```

## Project Structure

- `index.html` - homepage.
- `blog/`, `contact/`, `page/` - inner pages.
- `script.js` - site interactions.
- `animate.css`, `normalize.css`, `style.css` - stylesheets.
- `images/`, `svg/`, `design/` - assets and design references.
